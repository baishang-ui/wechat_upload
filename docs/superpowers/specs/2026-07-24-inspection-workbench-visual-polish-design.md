# 检验工作台弹层显示优化设计

## 目标

保持现有 88vh 固定高度、独立滚动区域与进出场动画，解决窄屏下按钮显示不全、操作区拥挤、内容层级杂乱的问题。

## 已确认方案

- 底部操作区拆为两层：分页控制独占一行，保存草稿使用全宽主按钮。
- 关闭控件与底部操作控件使用可控的 `view` 按钮结构，规避原生 `button` 在组件 Flex 布局中的默认宽度干扰；关闭样式与记录弹层一致。
- 标题容器允许收缩并截断长文本，关闭按钮始终完整显示。
- 识别操作使用可控的 `view` 按钮：常规屏幕保持双列，窄屏改为单列，避免原生 `button` 默认尺寸导致“从相册选择”被裁切。
- 表单与测量区域在窄屏下改为单列，图片区域由三列降为两列。
- 卡片、间距和状态标签保持一致的视觉层级，不改变现有业务流程。

## 验收标准

1. 320px 至常见手机宽度下，底部所有按钮文字完整可见。
2. 页码控制与保存操作不相互挤压。
3. 标题过长时不覆盖或挤压关闭按钮。
4. 内容区仍可独立纵向滚动，标题栏和操作栏固定。
5. 识别按钮、输入框和照片卡片在窄屏下无横向溢出。
