# 识别记录删除与列表骨架屏设计

日期：2026-07-23

## 目标

1. 识别记录卡片提供明确的删除按钮。
2. 本地记录可以删除本地数据和本地图片。
3. 服务器记录可以删除对应服务器检验数据，并清理关联本地副本。
4. 采购待检任务列表与识别记录列表在首次加载或空列表刷新时显示带入场动画的骨架屏。
5. 加载期间不提前显示空状态。
6. 每张识别队列卡片显示阶段式识别进度条。

## 删除语义

采用“按任务物料记录删除”的专用接口。

### 采购质检记录

- 删除指定 `task_id + item_id` 对应的检验草稿及历史检验数据。
- 保留采购质检任务和物料本身。
- 删除后重新计算任务的检验日期和完成状态，避免任务卡片保留已删除记录的状态。
- 不影响同一采购任务下的其他物料。

### 独立报告

- 独立报告任务只有一个物料时，删除整个独立任务，由数据库级联删除物料。
- 若数据异常并包含其他物料，则仅删除指定物料的检验数据，避免扩大删除范围。

### 本地副本

- 纯本地记录按本地记录 ID 删除，并删除对应持久化图片。
- 服务器记录删除成功后，清理所有匹配 `task_id + item_id` 的本地同步副本和图片。
- 服务器删除失败时不清理本地副本，界面保留记录并提示错误。

## 后端接口

新增：

`DELETE /customer-orders/api/purchase-orders/quality-inspections/{task_id}/items/{item_id}/record`

行为：

- 复用现有质检访问权限校验。
- 校验任务及物料存在且物料属于该任务。
- 采购质检清理物料备注中的 `inspection_draft`、`historical_inspections`、签字和报告等该记录派生数据。
- 独立报告按上述删除语义处理。
- 提交事务后返回删除类型、任务 ID、物料 ID。
- 不存在时返回 404；关联不匹配时同样返回 404，避免泄露其他任务数据。

## 前端删除交互

- 所有识别记录卡片右侧显示红色描边“删除”按钮。
- 删除按钮使用 `catchtap`，不触发卡片的打开动作。
- 点击后显示二次确认弹窗，文案区分本地记录和服务器记录。
- 删除进行中记录其 ID，按钮显示加载态并禁止重复操作。
- 删除成功后刷新识别记录列表；服务器采购记录删除后同步刷新待检任务列表。
- 若正在编辑被删除记录，则关闭编辑弹窗并清空相关编辑状态。

## 骨架屏

### 显示规则

- 采购任务：`taskLoading` 为真且 `taskItems` 为空时显示任务骨架。
- 识别记录：增加 `historyLoading`；加载中且 `historyRecords` 为空时显示记录骨架。
- 分页加载更多时保留真实列表，只显示现有底部加载提示。
- 加载完成后才允许显示空状态或错误状态。

### 结构

- 任务骨架：三张任务卡，包含编号行、日期摘要、状态胶囊和物料摘要占位。
- 记录骨架：三张左侧缩略图占位、右侧标题/客户/规格/状态行占位，与真实记录卡片尺寸接近。

### 动画

- 卡片使用逐项延迟的淡入和轻微上移动画。
- 占位块在入场后持续柔和横向 shimmer。
- 动画只改变 `opacity`、`transform` 和背景位置，避免布局抖动。

## 识别队列进度条

- 每张识别队列卡片在阶段文案下方显示进度轨道和百分比。
- 使用现有队列状态映射阶段进度，不伪造后端真实处理百分比：
  - `queued`：10%，等待识别。
  - `preparing`：35%，处理图片。
  - `recognizing`：从 70% 视觉展示为缓慢推进至 90%，表示模型处理中。
  - `ready`：100%，待人工审核。
  - `failed`：保留失败阶段的可见进度并使用红色。
  - `skipped`：0% 或当前停止位置，使用灰色。
- 状态切换时宽度平滑过渡；识别中的进度条增加轻微流光，不使用高频闪烁。
- 进度计算提取为纯函数并覆盖状态映射测试。

## 测试策略

### 前端

- 服务层测试：服务器删除请求方法和路径正确。
- 历史服务测试：按 `task_id + item_id` 清理匹配本地副本及图片，不影响其他记录。
- UI 结构测试：两个列表均存在骨架结构、加载条件和入场动画；所有记录均有删除按钮。
- 识别队列测试：各状态映射到预期进度，卡片包含进度轨道、百分比和识别中动画。
- 类型检查及完整测试套件。

### 后端

- 采购质检删除只清理指定物料记录，保留任务及其他物料。
- 独立报告删除任务及关联物料。
- 不存在和任务物料不匹配返回 404。
- 删除后历史接口不再返回该记录，任务状态与日期正确重算。

## 非目标

- 不提供回收站或恢复功能。
- 不删除采购订单、采购质检任务或未选中的其他物料。
- 不改变记录卡片现有左侧缩略图布局。
