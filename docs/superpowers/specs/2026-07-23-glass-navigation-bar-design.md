# 全页面顶部毛玻璃导航栏设计

## 背景

当前首页和日志页使用自定义 `navigation-bar`，但分别传入不透明的 `#f3f6f8` 与 `#FFF`；登录页仍使用微信原生导航栏。底部 `floating-tabs` 已采用半透明背景、背景模糊和饱和度增强，因此顶部和底部的材质语言不一致。

## 目标

- 登录页、首页、日志页全部使用一致的毛玻璃顶部栏。
- 毛玻璃参数与底部栏保持一致：`rgba(246, 249, 252, .48)`、`blur(24rpx)`、`saturate(132%)`。
- 保持顶部栏现有高度、安全区、标题、返回按钮和胶囊避让逻辑不变。
- 首页骨架屏与真实页面保持一致，加载期间不出现纯色顶部栏闪烁。
- 不改变页面业务逻辑、滚动区域和底部栏行为。

## 方案

### 公共导航组件

在 `miniprogram/components/navigation-bar/navigation-bar.scss` 中统一实现玻璃材质：

- 导航栏内部背景使用半透明浅色。
- 添加 `-webkit-backdrop-filter` 与标准 `backdrop-filter`。
- 添加轻微底部边界和阴影，模拟底栏的高光边缘，但保留顶部栏的矩形轮廓，不复制底栏的胶囊圆角。
- 保持文字与返回图标位于玻璃层上方，颜色继续由组件属性控制。

组件仍保留 `background` 属性以兼容调用方，但本项目全部页面统一传入毛玻璃背景色，避免内联纯色覆盖公共样式。

### 页面接入

- 首页：把顶部栏背景从 `#f3f6f8` 改为统一半透明色。
- 日志页：把顶部栏背景从 `#FFF` 改为统一半透明色。
- 登录页：将 `navigationStyle` 改为 `custom`，注册并插入公共 `navigation-bar`，标题为“账号登录”，不显示返回按钮；调整内容顶部间距，避免改为自定义导航后重复计算安全区。
- 首页骨架屏：同步其静态导航栏背景及玻璃样式，使首屏占位与实际页面一致。

## 兼容与降级

不支持 `backdrop-filter` 的运行环境仍会显示半透明浅色背景、边界和阴影，标题和交互不会受影响。支持该属性的微信客户端显示完整毛玻璃效果。

- 增加 UI 一致性测试，断言三个页面均使用公共导航栏和统一半透明背景。
- 断言公共导航组件包含模糊与饱和度参数。
- 断言首页骨架屏不再使用纯色导航背景。
- 运行完整测试与 TypeScript 类型检查。
