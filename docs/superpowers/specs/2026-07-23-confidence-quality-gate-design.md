# 质检识别置信度质量门控设计

日期：2026-07-23

## 问题

真实模型测试显示，清晰图片的 47 个字段全部返回 `1.0`，包括空白字段；严重模糊图片则全部返回 `null`。因此模型置信度是未校准的自评值，无法单独识别“格式正确但内容错误”的数据。

## 目标

在保留模型原始分数的同时，加入确定性质量门控、采购任务数据交叉校验和表格逻辑校验，让高分错误数据仍能被标红或标黄。

## 判定顺序

1. 确定性格式错误：红色。
2. 与采购任务预填数据不一致：红色。
3. 显式规格范围外：红色。
4. 样本判定存在但测量值缺失：黄色。
5. 置信度分布失真：非空识别字段降级为黄色。
6. 原始分数 `<0.60`：红色；`0.60–0.79`：黄色；`>=0.80`：正常。

高优先级规则覆盖模型高分。

## 置信度失真检测

收集实际非空识别字段对应的数字分数。满足以下条件时视为未校准：

- 至少 8 个有效分数；并且
- 至少 90% 的分数相同；并且
- 该重复分数不低于 0.95。

失真时：

- 与采购预填值明确一致的字段可视为正常，因为值由业务数据验证。
- 其他非空字段统一降级为黄色。
- 可选空字段保持正常，不制造无意义警告。
- 格式错误、业务不一致和范围错误仍标红。

## 采购数据交叉校验

当队列任务来源为采购待检时，将识别结果与加入队列时保存的 `taskPrefill` 比较：

- 客户、供应商、订单编号、型号、到货数量不一致：红色。
- 比较前忽略大小写、空白和常见标点差异。
- 模型字段为空并被服务器预填值补全后，视为业务数据已验证，不因缺少模型分数标黄。

## 表格逻辑校验

- 支持 `a-b`、`a~b`、`a～b` 和 `center±tolerance` 显式范围。
- 数字测量值超出显式范围：红色。
- 对应样本判定为 `OK/NG` 但测量值为空：黄色。
- 非数字、非范围、非允许判定文本：红色。
- 不对只有名义值但没有公差的规格擅自判断超差。

## 模型提示词

后端提示词增加：

- 空字符串的置信度必须为 `null`。
- 不得为全部字段批量填写同一分数。
- 只有字符清晰、边界明确且无歧义时才可高于 0.9。
- 手写、遮挡、模糊、表格错位必须降低分数。
- `1.0` 仅用于完全无歧义字段。

## 验收标准

- 全 1.0 返回被识别为失真，非空 OCR 字段标黄。
- 采购字段不一致即使模型给 1.0 仍标红。
- 采购字段一致且由预填数据验证时不标黄。
- 显式规格范围外测量值标红。
- 判定存在但测量值缺失标黄。
- 可选空字段不因无分数产生噪声高亮。
- 用户修改风险字段后高亮消失，原始分数保留。
